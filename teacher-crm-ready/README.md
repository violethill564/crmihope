# Преподаватель CRM

Готовая PWA-версия приложения для публикации на HTTPS-хостинге.

## Файлы
- `index.html` — приложение
- `manifest.json` — настройки PWA
- `sw.js` — Service Worker и обновление кэша
- `icon-192.png`, `icon-512.png` — иконки приложения

## Публикация
Разместите содержимое этой папки на HTTPS-хостинге. После первого открытия в поддерживаемом браузере приложение можно установить как отдельное приложение.

Firebase в приложении продолжает работать через сеть; данные не хранятся в Service Worker.
